# G&M Consultores Contables & Tributarios

Sitio web profesional para **G&M Consultores Contables & Tributarios**, una empresa ubicada en Caracas
que ofrece asesoría presencial y remota a clientes de toda Venezuela.

[Ver aplicación publicada](https://mile-servicios.netlify.app)

## Español

### El problema

G&M Consultores Contables & Tributarios necesitaba presentar sus áreas de atención de forma clara,
transmitir confianza y facilitar que un cliente pudiera iniciar una consulta
desde su teléfono.

### La solución

Se diseñó una página adaptable a teléfonos y computadoras que organiza la
oferta en tres áreas principales:

- Trámites legales.
- Deberes formales y fiscales.
- Servicios contables.

La web también muestra los organismos relacionados con sus gestiones, explica
el proceso de atención e incorpora contacto directo mediante WhatsApp.

### Funciones

- Diseño responsive para móvil y escritorio.
- Navegación por secciones.
- Catálogo claro de servicios y áreas de gestión.
- Dos enlaces directos a WhatsApp con mensajes preparados para los administradores.
- Información de cobertura: Caracas y asesoría remota nacional.
- Aviso visible de servicio privado e independiente.
- HTML semántico y soporte para navegación por teclado.

### Tecnologías

- React
- TypeScript / TSX
- CSS
- Vite
- Git y GitHub
- Netlify para la publicación final

### Uso de inteligencia artificial

La inteligencia artificial fue utilizada como asistente para generar una
primera estructura, proponer estilos y apoyar la revisión del código. Jorge
Añanguren definió el objetivo, recopiló los requisitos reales del cliente,
seleccionó el contenido, revisó cada avance y solicitó los cambios finales.

### Ejecutar localmente

```bash
npm install
npm run dev
```

Abrir el proyecto en Visual Studio Code permite revisar y modificar los archivos
de la carpeta `app/`.

## English

### The problem

G&M Consultores Contables & Tributarios needed a clear and trustworthy website to present its service
areas and help potential clients start a consultation from their phones.

### The solution

A responsive landing page was designed around three primary service areas:

- Legal procedures.
- Formal and tax obligations.
- Accounting services.

The website also presents the institutions related to these services, explains
the client journey, and provides direct WhatsApp contact.

### Features

- Responsive mobile and desktop design.
- Section-based navigation.
- Clear service and institution catalog.
- Two direct WhatsApp links with prefilled messages for the administrators.
- Coverage information for Caracas and remote service across Venezuela.
- Clear independent-service disclaimer.
- Semantic HTML and keyboard-friendly navigation.

### Technologies

- React
- TypeScript / TSX
- CSS
- Vite
- Git and GitHub
- Netlify for the final deployment

### AI disclosure

Artificial intelligence was used as an assistant for the initial structure,
visual suggestions, and code review. Jorge Añanguren defined the objective,
gathered the real client requirements, selected the content, reviewed each
milestone, and requested the final changes.
